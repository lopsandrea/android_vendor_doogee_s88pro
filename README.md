Proprietary files for DOOGEE S88 Pro (s88pro)
=============================================

What LineageOS takes from the stock DOOGEE ROM, Android 10:

    DOOGEE/S88Pro_EEA/S88Pro:10/QP1A.190711.020/1592876742:user/release-keys

vendor.img
----------

The stock vendor partition, whole and unmodified. The device tree puts it in
super as a prebuilt image (`BOARD_PREBUILT_VENDORIMAGE`), and its Android 10
HALs and libraries run under the newer system through VNDK 29.

proprietary/vendor/etc/vintf/manifest/android.hardware.gpu@1.0-service.xml
---------------------------------------------------------------------------

The VINTF fragment the stock vendor keeps apart for its GPU HAL. The device
tree joins it to the device manifest through `DEVICE_MANIFEST_FILE`.

Nothing from the stock system image is used: see `proprietary-files.txt` in
the device tree for why.

Makefiles
---------

`Android.bp`, `Android.mk`, `BoardConfigVendor.mk` and `s88pro-vendor.mk` are
generated by `device/doogee/s88pro/setup-makefiles.py` and must not be edited
by hand.
